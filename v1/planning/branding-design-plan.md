# Ranyn Labs - Branding, Design, and Website Master Plan

This document outlines the strategic design framework for Ranyn Labs.

## 1. Identity & Narrative
- **Name**: Ranyn Labs
- **Tagline**: Intelligent Systems. Ethical Engineering. Global Impact.
- **Mission**: Delivering secure, high-performance systems and transformative analytics while adhering to strict ethical engineering standards.
- **Tone & Voice**: Pragmatic, expert, transparent, and slightly playful/expressive to represent modern multidisciplinary expertise.

## 2. Visual & Branding Direction
Ranyn Labs uses the **Expressive Design System**, combining technical precision with vibrant, dynamic details:
- **Typography**: IBM Plex Mono (monospaced family that communicates code, system architecture, and modern tech).
- **Color Palette**:
  - **Primary**: `#db2777` (Deep Pink/Magenta - represents creativity, energy, and human-centric engineering).
  - **Secondary**: `#2563eb` (Royal Blue - represents stability, trust, and structural security).
  - **Neutral Dark**: `#111827` (Slate Gray - main body text).
  - **Neutral Light**: `#f3f4f6` (Light Gray - backgrounds).
  - **Accents**: Success (`#16a34a`), Warning (`#d97706`), Danger (`#dc2626`).

## 3. Scope of Output Documents
To establish a complete brand foundation, we output four distinct plan documents:
1. **Product Requirements Document (PRD)** (`prd.md`): Defines the target audience, technical specifications, and key features.
2. **User Journey Map** (`user-journey-map.md`): Details the touchpoints for prospective clients, engineers, and partners.
3. **Brand Guideline** (`brand-guideline.md`): Visual system rules (margins, typography weights, color usage dos & don'ts).
4. **Mock-up Outline** (`mock-up.md`): Visual and structural blueprint of the landing pages.

## 4. Execution Phases
- **Alpha Stage (Current)**: Plain HTML5, CSS3, and Vanilla JavaScript (`v1/`).
- **Beta Stage (Future)**: Next.js, Tailwind CSS, TypeScript, SQLite/PostgreSQL.
